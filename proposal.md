# Pixel-Canvas

# Repository
https://github.com/awkwardzie/Pixel-Canvas

# Description
Pixel Canvas is going to create a digital canvas where the user can create artwork by selecting pixels. This is relevant to media and digital arts because the user can create pixel artwork.

# Features
Feature 1
- Going to use a color picker where you have to select of number of times for a color (1=Red, 2=Orange, etc.)
Feature 2
- Going to use a canvas that uses pixels (squares)
Feature 3
- Uses user input to select a canvas preference before displaying canvas window

# Challenges
1 = Color picker
2 = Selecting window size before canvas
3 = Using user input to select color
4 = Uses cursor to select

# Outcomes
Ideal Outcome:
The program is going to ask for a canvas (square, landscrape, portrait) before opening up a window that has the desired canvas. With user input, the user can use their cursor to select which color they want for a pixel, and the program will memorize the color so that progress is not loss as they keep going.
Minimal Viable Outcome:
The program opens up a square-sized window and users user input to select at least one color to create a pixel artwork.
