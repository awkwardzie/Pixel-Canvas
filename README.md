# Project Description
A black canvas that can be used for pixel artwork. It uses a grid system and a color palette sidebar to select colors and decorate the canvas. It is meant to be simple file wise so that there are no complications when running the program. I initially want to use a color-cycling function for this program, but I ended up changing it at the end. It felt tedious to me, and a color palette function would be simpler and more user friendly. I kept the three canvases and their sizing felt appropriate to me. I believe if I wanted to further improve on this program there would be a couple changes I would make. One change I would make it adding a user input for if they want a white or black canvas. Another would be how many pixels the user would want their canvas. One last feature I would add is saving the canvas image file.
